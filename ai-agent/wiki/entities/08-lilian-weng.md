# Lilian Weng

AI 研究者，博客 **Lil'Log** 作者；曾任 OpenAI Safety Systems 负责人。

## 为什么在 agent 领域重要

她 2023-06 的 [[sources/04-llm-powered-autonomous-agents]] 是**这一领域被引用最多的入门综述**：把 AutoGPT 热潮期散落的论文归纳为 **Planning / Memory / Tool use** 三组件架构。此后几乎所有 agent 教程、课程与面试题的知识框架都沿用这个三分法。

## 该文提出/普及的关键点

- 三组件架构图（对应 [[concepts/14-augmented-llm]] 的另一种表述）
- 人脑记忆分类 → agent 记忆分层的映射（[[concepts/26-memory]]）
- MIPS / ANN 检索作为长期记忆的技术底座（[[concepts/27-rag]]）
- 三大挑战：有限 context length、长程规划与纠错困难、自然语言接口不可靠 —— 至今仍是主线问题
